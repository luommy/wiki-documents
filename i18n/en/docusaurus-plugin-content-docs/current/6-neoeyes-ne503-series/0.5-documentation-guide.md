# Documentation Guide

Choose an entry point by task. You do not need to read every page.

## Choose by role

### Evaluator / first deployment

Goal: bring the device online and verify the camera, streams, and AI.

Start with [Quick Start](./1-quick-start.md). For daily operation, see the [User Guide](./2-user-guide/0-dashboard.md).

### App developer

Goal: build and deploy an AI container app.

| Order | Document | Use |
|:--|:--|:--|
| 1 | [Resources](./4-application-guide/3-resources.md) | SDK, API, samples, and build resources |
| 2 | [Hello World](./4-application-guide/1-hello-world.md) | Build and run a first app |
| 3 | [Cookbook: Parking Lot](./4-application-guide/2-cookbook/0-parking-lot.md) | Reference a complete app flow |

### System integrator

Goal: integrate video streams, AI events, and device-management interfaces.

| Document | Use |
|:--|:--|
| [Resources](./4-application-guide/3-resources.md) | API, event protocol, SDK, and deployment material |
| [Video and Imaging](./2-user-guide/1-media-and-image.md#rtsp-integration) | Get an RTSP URL and verify streaming |

### Model engineer

Goal: train, compile, and deploy HEF models.

| Order | Document | Use |
|:--|:--|:--|
| 1 | [Model Training and HEF](./4-application-guide/4-model-training-and-hef.md) | Complete training, compilation, and deployment flow |
| 2 | [AI Apps and Models](./2-user-guide/2-applications-and-models.md) | Import and verify models in the web console |

### Platform developer

Goal: understand and build the platform software.

| Order | Document | Use |
|:--|:--|:--|
| 1 | [System Architecture](./3-software-guide/0-system-architecture.md) | Platform layers and main data flows |
| 2 | [Developer Guide](./3-software-guide/1-developer-guide.md#2-start-the-docker-build-environment) | Set up the environment and build a release package |
| 3 | [System Flashing](./3-software-guide/2-system-flashing.md) | Flash the system and upgrade the OS |

### Hardware engineer

Goal: review boards, interfaces, and wiring.

Start with the [Hardware Guide](./2-hardware-guide/0-specifications.md).

## When something goes wrong

Use [Troubleshooting](./5-troubleshooting.md): symptom → check → result → next step.
