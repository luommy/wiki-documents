# Temperature & Humidity Sensor

## 概览

Sensirion SHT3x-DIS（SHT30）是一款全校准、线性化并带温度补偿的数字输出温湿度传感器，采用标准 I2C 接口通信。其高精度、低功耗特性及紧凑的 DFN 封装，使其成为环境监测、智能家居和工业控制等应用的理想选择。

![SHT30-DIS](https://resources.camthink.ai/wiki/img/hardware-dev-resources/temperature-humidity-sensor/temp-humidity-sht30.png)

## 1. 产品概述

### 1.1 产品特点

- **全校准数字输出**：湿度精度 ±2%RH，温度精度 ±0.2°C，无需额外校准
- **线性化与温度补偿**：传感器输出已经过线性化处理和温度补偿
- **低功耗设计**：空闲电流仅 0.2µA，适合电池供电场景
- **标准 I2C 接口**：支持最高 1MHz 通信速率，两个可选从地址
- **宽供电范围**：2.15V ~ 5.5V，兼容多种供电系统
- **紧凑封装**：8-Pin DFN 封装（2.5 × 2.5 × 0.9mm），节省 PCB 空间

### 1.2 NE301 应用场景

在 NE301 传感器扩展板中，温湿度传感器作为**环境上下文传感器**，为每次抓拍提供环境温湿度元数据。这些数据随抓拍图片一同上报，帮助后端分析环境因素对检测结果的影响（如高温高湿环境下传感器精度变化），也可用于判断设备工作环境是否异常。

| 应用场景 | 说明 |
|:---|:---|
| 环境监测 | 抓拍时附带温湿度数据，辅助环境趋势分析 |
| 智能家居 | 记录环境温湿度变化，联动 NE301 抓拍和空调控制 |
| 工业控制 | 监控生产线环境条件，异常温湿度触发报警抓拍 |
| 仓储管理 | 追踪仓库环境变化，确保存储环境合规 |

## 3. 引脚定义

SHT30 采用 8-Pin DFN 封装，引脚定义如下：

| 引脚 | 名称 | 功能描述 |
|:---|:---|:---|
| 1 | SDA | I2C 串行数据 |
| 2 | ADDR | I2C 地址选择 |
| 3 | ALERT | 温湿度报警输出（开漏） |
| 4 | SCL | I2C 串行时钟 |
| 5 | VDD | 电源输入（2.15V ~ 5.5V） |
| 6 | nRESET | 复位引脚（低电平有效） |
| 7 | R | 无电气功能（连接至 VSS） |
| 8 | VSS | 接地 |


> **I2C 从地址选择**：ADDR 引脚连接到逻辑低电平时，从地址为 0x44；连接到逻辑高电平时，从地址为 0x45。
