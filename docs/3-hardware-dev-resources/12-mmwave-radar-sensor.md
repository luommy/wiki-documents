# mmWave Radar Sensor

## 概览

RKB1161LX1 是由矽杰微电子（厦门）有限公司开发的 24GHz 毫米波雷达模块，采用 FMCW 调制方式，支持运动检测与存在检测。模块可穿透非金属外壳，能检测人体呼吸等微小幅度的运动，适用于智能安防、智能家居等场景。

![24GHz-mmWave-RKB1161L](https://resources.camthink.ai/wiki/img/hardware-dev-resources/mmwave-radar-sensor/mmwave-rkb1161l.png)

## 1. 产品概述

### 1.1 产品特点

- **运动与存在检测**：不仅能检测人体移动，还能检测呼吸等微小幅度运动
- **非金属穿透**：可穿透塑料、玻璃、木材、陶瓷等非金属外壳
- **丰富数据输出**：可输出目标距离、速度、方位角度、信号强度等信息
- **低功耗**：平均电流仅 100µA，适合电池供电场景
- **超小尺寸**：模块尺寸仅 20×20×1.0mm，便于集成
- **OTA 升级**：支持在线参数配置和固件空中升级

### 1.2 NE301 应用场景

在 NE301 传感器扩展板中，毫米波雷达作为**高精度存在检测传感器**，能够穿透非金属外壳检测人体呼吸等微小运动，实现比 PIR 更精准的触发抓拍。雷达检测到人员存在或活动后，通过 IO 信号唤醒 NE301 执行抓拍。

| 应用场景 | 说明 |
|:---|:---|
| 智能安防 | 检测区域内人员存在，触发精准抓拍 |
| 智能家居 | 联动 NE301 抓拍记录人员进出事件 |
| 健康监测 | 检测呼吸等微小运动，触发异常状态抓拍 |
| IoT 网关 | 低功耗存在检测，按需唤醒 NE301 抓拍 |

## 3. 引脚定义

RKB1161LX1 采用 5 pin、2.0mm 间距排针封装（不含排针），引脚定义如下：

| 引脚 | 名称 | 功能描述 |
|:---|:---|:---|
| 1 | OUT | 有目标输出 3V，无目标输出 0V |
| 2 | UART_TX | TTL 电平数据发送（连接主机 RX） |
| 3 | UART_RX | TTL 电平数据接收（连接主机 TX） |
| 4 | GND | 接地 |
| 5 | VCC | 电源输入（3.3V ~ 5V） |
