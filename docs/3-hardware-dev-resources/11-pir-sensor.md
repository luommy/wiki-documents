# PIR Sensor

## 概览

Nicera NP624M-F 是一款数字双元 PIR（被动红外）传感器，内置 14-bit ADC 和 25-bit 配置寄存器，支持中断模式与串行输出模式。凭借极低的工作电流（典型 3µA）和抗射频干扰设计，非常适合电池供电的物联网设备进行人体移动检测。

![PIR-NP624M-F](https://resources.camthink.ai/wiki/img/hardware-dev-resources/pir-sensor/pir-np624m-f.png)

## 1. 产品概述

### 1.1 产品特点

- **数字双元 PIR 传感器**：内置信号处理电路，直接输出数字信号
- **超低功耗**：典型工作电流仅 3µA，适合电池供电场景
- **抗射频干扰**：良好的 RF 抗扰度设计，适应复杂电磁环境
- **高精度 ADC**：14-bit 模数转换器，精确捕捉红外信号变化
- **灵活配置**：25-bit 配置寄存器，支持中断模式与串行输出模式
- **紧凑封装**：4 pin 封装，感应元尺寸 2.3×1mm

### 1.2 NE301 应用场景

在 NE301 传感器扩展板中，PIR 传感器作为**事件触发源**，实现按需抓拍。当 PIR 检测到人体移动时，通过 IO 触发信号唤醒 NE301 执行抓拍，避免持续拍摄产生大量无效画面，显著节省存储、带宽和电池电量。

| 应用场景 | 说明 |
|:---|:---|
| 安防监控 | 人体移动触发抓拍，仅保留有事件的画面 |
| 工地防范 | 检测施工区域人员活动，触发按需抓拍 |
| 野生动物监测 | 电池供电场景下，PIR 触发抓拍节省功耗 |
| 入侵告警 | 检测到入侵行为后触发抓拍并通过 MQTT 上报 |

> 详细接入方案请参考 [PIR 传感器集成指南](/docs/neoeyes-ne301-series/application-guide/pir-sensor-integration)。

## 3. 引脚定义

NP624M-F 采用 4 pin 封装，引脚定义如下：

| 引脚 | 名称 | 功能描述 |
|:---|:---|:---|
| 1 | INT/Dout | 中断输出 / 串行数据输出 |
| 2 | VDD | 电源输入（1.6V ~ 3.6V） |
| 3 | Serial_In | 串行数据输入 / 时钟输入 |
| 4 | GND | 接地 |
