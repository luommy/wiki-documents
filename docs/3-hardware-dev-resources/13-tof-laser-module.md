# dToF Laser Module

## 概览

北极芯微 DTS6012M 是一款全集成单通道直接飞行时间（dToF）激光测距小型模组，内置 VCSEL 激光器和单光子探测器（SPAD），支持 I2C 与 UART 双接口通信。凭借 0.2m~20m 的宽量程、最高 250fps 帧率及 Class 1 激光安全认证，适用于智能门禁、无人机定高、机器人避障等应用场景。

![dToF-DTS6012M](https://resources.camthink.ai/wiki/img/hardware-dev-resources/tof-laser-module/dtof-dts6012m.png)

## 1. 产品概述

### 1.1 产品特点

- **全集成设计**：内置 VCSEL 激光器 + SPAD 探测器 + 信号处理电路，无需外部光学元件
- **高帧率**：最高 250fps，满足高速动态场景需求
- **宽量程**：0.2m ~ 20m，覆盖近距离到远距离测量
- **抗阳光干扰**：100Klux 阳光下仍可达到 12m 测距能力
- **双目标探测**：可同时识别前后两个目标的距离
- **温度补偿**：内置温度传感器，自动校正温度漂移
- **反射率校正**：支持不同反射率目标的精度校正
- **双接口**：支持 UART 和 I2C 通信，通过 GPIO 引脚切换

### 1.2 NE301 应用场景

在 NE301 传感器扩展板中，dToF 模组作为**距离感知传感器**，可为目标抓拍提供距离信息。当检测到目标进入预设距离范围时，触发 NE301 执行抓拍；同时距离数据可作为抓拍元数据，辅助 AI 模型判断目标大小。

| 应用场景 | 说明 |
|:---|:---|
| 智能门禁 | 检测人员接近距离，近距离时触发抓拍 |
| 机器人避障 | 提供障碍物距离数据，辅助 NE301 场景理解 |
| 车辆检测 | 距离范围内触发 NE301 抓拍，记录车辆进出 |
| 工业检测 | 配合 NE301 抓拍，量化位移或液位变化 |

## 3. 引脚定义

DTS6012M 采用 6-pin 连接器，引脚定义如下：

| Pin | 名称 | 功能描述 |
|:---|:---|:---|
| 1 | 3V3_LASER | 激光器升压电路供电 (3.3V) |
| 2 | 3V3 | 低压电路供电 (3.3V) |
| 3 | UART_TX / I2C_SDA | UART 发送 / I2C 数据 |
| 4 | UART_RX / I2C_SCL | UART 接收 / I2C 时钟 |
| 5 | GPIO | 模式选择 (下拉=UART, 上拉/悬空=I2C) |
| 6 | GND | 接地 |
