# Accelerometer & Gyroscope

## 概览

STMicroelectronics LSM6DSR 是一款高性能六轴惯性测量单元（IMU），集成了 3D 数字加速度计和 3D 数字陀螺仪。凭借嵌入式机器学习核心、可编程有限状态机（FSM）及 Sensor Hub 功能，该芯片在运动跟踪、AR/VR、光学防抖和工业物联网等应用中表现出色。

![LSM6DSR](https://resources.camthink.ai/wiki/img/hardware-dev-resources/accelerometer-gyroscope/imu-lsm6dsr.png)

## 1. 产品概述

### 1.1 产品特点

- **六轴集成**：3D 数字加速度计 + 3D 数字陀螺仪，单芯片解决方案
- **超低功耗**：低功耗模式下电流低至微安级，适合电池供电设备
- **多接口支持**：SPI、I2C、MIPI I3CSM，灵活适配不同主控平台
- **嵌入式智能功能**：计步器、运动检测、倾斜检测、自由落体等多种算法
- **可编程 FSM**：16 个独立有限状态机，支持自定义运动识别逻辑
- **Sensor Hub**：最多连接 6 个传感器（2 内部 + 4 外部），集中数据采集
- **智能 FIFO**：9 KB 容量，支持数据压缩（最高 3 倍），降低主控唤醒频率

### 1.2 NE301 应用场景

在 NE301 传感器扩展板中，六轴 IMU 作为**姿态与震动传感器**，可检测设备的安装姿态、位移和震动事件。当检测到设备被移动或发生异常震动时，可触发 NE301 抓拍并通过 MQTT 上报告警；姿态数据也可用于图像防抖或设备状态监测。

| 应用场景 | 说明 |
|:---|:---|
| 设备安全 | 检测 NE301 被移动或碰撞，触发报警抓拍 |
| 安装校准 | 读取姿态数据，辅助调整 NE301 安装角度 |
| 震动检测 | 监测设备异常震动，触发事件抓拍并上报 |
| 设备监测 | 长期记录设备姿态变化，评估安装稳定性 |

## 3. 引脚定义

LSM6DSR 采用 LGA-14L 封装，引脚定义如下：

| 引脚 | 名称 | 功能描述 |
|:---|:---|:---|
| 1 | SDO/SA0 | SPI 数据输出 / I2C 地址选择 |
| 2 | SDx | I2C 串行数据 / 辅助 SPI 数据 |
| 3 | SCx | I2C 串行时钟 / 辅助 SPI 时钟 |
| 4 | INT1 | 可编程中断 1 |
| 5 | Vdd_IO | I/O 引脚电源 |
| 6 | GND | 接地 |
| 7 | GND | 接地 |
| 8 | Vdd | 主电源 |
| 9 | INT2 | 可编程中断 2 / 数据使能（DEN） |
| 10 | OCS_Aux | 辅助 SPI 片选（未使用时悬空） |
| 11 | SDO_Aux | 辅助 SPI 数据输出（未使用时悬空） |
| 12 | CS | SPI 片选 / I2C 模式选择（低电平有效） |
| 13 | SCL | I2C/MIPI I3CSM 时钟 / SPI 时钟 |
| 14 | SDA | I2C/MIPI I3CSM 数据 / SPI 数据输入 |


> **地址选择**：SA0 引脚连接到逻辑低电平时，I2C 从地址为 0x6A；连接到逻辑高电平时，从地址为 0x6B。
