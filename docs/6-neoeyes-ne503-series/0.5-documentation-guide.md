# Documentation Guide

NE503 文档按角色划分使用路径。不同角色需要的内容不同——本页帮你找到自己的起点：每个角色给出**核心目标**、**需要读的内容板块**（链接直达对应章节）与**建议阅读顺序**，不必从头通读全部文档。

## 文档板块总览

| 板块 | 内容 | 适合谁 |
|------|------|--------|
| Product Information | 产品定位、核心能力、接口与规格 | 所有人（5 分钟了解产品） |
| Quick Start | 开箱到上线的线性闭环（约 10 分钟） | 试机 / 首次部署 |
| User Guide | Web 控制台全部功能：画面、外设、模型管理、运维、安全、接线 | 运维 / 安装人员 |
| Hardware Guide | 板级硬件：核心板、接口板、开发调试 | 硬件工程师 |
| Software Guide | 系统架构、源码构建、烧录、版本矩阵 | 平台开发者 |
| Application Guide | 应用开发（SDK/教程/模型训练）、Cookbook 项目实录、Reference 参考（App/SDK/REST/视频/事件） | 应用开发者 / 集成商 / 模型工程师 |
| Troubleshooting | 按症状组织的故障排查 FAQ | 所有人（遇到问题时查） |

## 按角色选起点

### 试机用户 / 首次部署

**目标**：开箱到设备上线，验证画面、码流与 AI 全部正常。

**路径就是 [Quick Start](./1-quick-start.md)**（§1→§6 约 10 分钟），走完设备即可上线。上线后的日常使用进[用户指南](./2-user-guide/0-dashboard.md)。

**目标**：开发自己的 AI 容器应用并部署到设备。

任何角色排障先进[故障排查](./5-troubleshooting.md)：按症状域（设备与网络 / 视频与流 / AI 与模型 / 应用与容器 / 事件与集成 / 存储与磁盘 / 烧录与外设 / 系统与服务）组织的「现象 → 原因 → 修复」FAQ。
