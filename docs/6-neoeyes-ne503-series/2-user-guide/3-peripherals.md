# Peripherals

“外设”页面集中管理 NE503 对外的硬件接口：音频、报警、门禁。所有项以开关或选项形式配置。

<img src="https://resources.camthink.ai/wiki/img/neoeyes-ne503-series/user-guide/peripherals/qs-peripherals.png" />

## I/O 控制

### 音频

- **麦克风输入**：开启设备麦克风采集，供“媒体”页面监听、对讲，或让应用采集音频。
- **扬声器输出**：开启设备扬声器输出，用于对讲回话或应用发声。

### 报警输入

- **报警输入**：报警输入开关。当前固件版本报警输入的信号上报（事件总线 / API）尚未开放，需要报警联动时由外部系统直接接线实现。
- **报警输入电平**：触发电平选择（`High` / `Low`）。当前固件版本该选项暂未生效，以固件更新说明为准。

> NE503 对外引出 1 路报警输入（接门磁、红外对射、烟感等开关量信号）。

### Wiegand 输出

- **Wiegand 通道 0 / 通道 1**：两路输出通道（继电器 + 电平），用于向门禁控制器等外部设备输出联动信号。

开启后对应通道输出有效电平。Wiegand 为输出接口，不用于接入读卡器。

## 联动说明

- **对讲**：“媒体”页面的 `Talk` 按钮，配合“麦克风输入”和“扬声器输出”开启。
- **AI 事件联动外部设备**：平台不内置「AI 检测 → 报警输出」的自动联动；由应用或业务系统订阅 AI 事件后自行执行（如驱动外部继电器）。
- **报警输入上报**：当前固件尚未接入事件总线，见上文报警输入一节。

> 各接口的物理接线与供电选择见[整机接线](./8-product-wiring.md)。
